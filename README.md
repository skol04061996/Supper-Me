# Supper Me — Global Cuisine Desi Vibes

Official single-page website for **Supper Me**, Kolkata's Continental QSR brand.

## Features
- **Interactive Menu & Drive Gallery**: Signature dishes with live Google Drive image support.
- **One-Tap Online Ordering**: Direct links to Swiggy, Zomato, and Ownly.
- **9 Outlet Locator**: Interactive Google Maps switcher for all Kolkata, Howrah, and Serampore outlets.
- **Instant WhatsApp Support**: Direct outlet inquiries and quick ordering.
